# 插件介绍

用户可以通过自然语言让 Bot 更换头像，也可以让 LLM 在对话过程中根据语气、情绪和氛围，自主决定是否调用工具修改昵称、个性签名和在线状态。

这个插件适合想让 Bot 的外在表现更贴合当前聊天场景的使用方式，例如在轻松、低落、忙碌、活跃等不同语境下，动态调整 QQ 资料状态。

## 功能特性

- 提供 5 个 LLM 可调用工具
  - 修改 QQ 头像
  - 修改 QQ 昵称
  - 修改 QQ 个性签名
  - 修改 QQ 在线状态
  - 修改 QQ 自定义状态（状态表情 + 自定义文字）
- 支持在 `on_llm_request` 生命周期向系统提示词注入工具说明
- 注入提示词可在插件配置中自定义
- 提示词支持 `{supported_statuses}` 占位符，自动展开为当前支持的在线状态名列表
- 提示词支持 `{supported_diy_emojis}` 占位符，自动展开为当前支持的自定义状态表情名列表
- 支持从当前消息或引用消息中提取图片作为新头像

## 适用平台

当前插件面向 `aiocqhttp` 协议端使用。

## 安装方式

将插件放入 AstrBot 插件目录，或通过插件仓库安装，然后在 AstrBot 面板中启用插件。

## 配置说明

请在 AstrBot 面板中进入插件配置页进行设置。

目前包含以下配置项：

### 工具启用开关

各工具分别通过独立的开关控制，默认开启「个性签名」「在线状态」「自定义状态」三个工具，避免用户只是发送/分享图片时被 LLM 误判为换头像指令。

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable_set_avatar` | `bool` | `false` | 启用「修改 QQ 头像」工具 |
| `enable_set_nickname` | `bool` | `false` | 启用「修改 QQ 昵称」工具 |
| `enable_set_longnick` | `bool` | `true` | 启用「修改 QQ 个性签名」工具 |
| `enable_set_status` | `bool` | `true` | 启用「修改 QQ 在线状态」工具 |
| `enable_set_diy_status` | `bool` | `true` | 启用「修改 QQ 自定义状态」工具（仅 NapCat 协议端支持）|

关闭后对应工具不会暴露给 LLM，模型也就无法调用它。配置修改后重新加载插件即可生效。

### `inject_profile_prompt`

- 类型：`bool`
- 默认值：`true`
- 作用：是否在 LLM 请求前注入 QQ 资料工具相关提示词

关闭后，插件工具仍然存在，但模型不会额外收到这段行为引导。

### `profile_prompt`

- 类型：`text`
- 默认值：内置一段引导模型按情绪自主决定是否修改昵称、签名、状态的提示词
- 作用：定义注入给 LLM 的说明文本

可在文本中使用占位符：

- `{supported_statuses}`：自动替换为当前插件内支持的在线状态名称列表
- `{supported_diy_emojis}`：自动替换为当前插件内支持的自定义状态表情名称列表

## 使用方式

### 1. 自然语言更换头像

这个插件不再依赖 `设置头像` 命令。

推荐使用方式：

- 当前消息直接发送图片，并附带自然语言，例如：`你把头像换成这个`
- 或引用一条带图消息，再补一句自然语言，例如：`把头像改成这张`

当模型理解到你的意图后，会调用头像工具，从当前消息或引用消息中提取图片并完成更换。

如果消息里没有图片，或者引用消息里也没有图片，工具会返回失败提示。

## LLM 工具

本插件注册了以下函数工具，供模型在合适时机调用：

- `qqprofile_set_avatar`
- `qqprofile_set_nickname`
- `qqprofile_set_longnick`
- `qqprofile_set_status`
- `qqprofile_set_diy_status`

建议配合合适的系统提示词或人格提示词使用，让模型理解：

- 资料修改是低频行为，不应频繁触发
- 在线状态必须从受支持列表中选择
- 当用户明确要求更换头像，且消息上下文里有图片时，可以调用头像工具

## 在线状态支持

当前内置支持的状态包括：

在线、Q我吧、离开、忙碌、请勿打扰、隐身、听歌中、被掏空、今日天气、我crush了、爱你、恋爱中、好运锦鲤、水逆退散、嗨到飞起、元气满满、一言难尽、难得糊涂、emo中、我太难了、我想开了、我没事、想静静、悠哉哉、去旅行、信号弱、出去浪、肝作业、学习中、搬砖中、摸鱼中、无聊中、timi中、睡觉中、熬夜中、追剧中、我的电量

如果模型传入了不支持的状态名，工具会返回失败信息，并附带当前可用状态列表。

## 自定义状态支持

除了上面的预设在线状态，插件还支持 QQ 的「自定义状态」，即一句自定义文字搭配一个状态表情。底层通过 NapCat 的 `set_diy_online_status` 接口实现，因此该功能**仅 NapCat 协议端支持**，其他协议端（如 LLOneBot / Lagrange）可能不可用。

- 自定义文字 `wording`：必填，由 LLM 根据当前氛围生成的一句简短状态文字。
- 状态表情 `emoji`：可选，必须从下面的「表情名」中选择；不传则只设置文字。

当前内置支持的状态表情包括：

脑阔疼、发呆、得意、流泪、发怒、酷、难过、困、鞭炮、嘘、奋斗、猪头、蛋糕、炸弹、太阳、捂脸、吃瓜、庆祝、调皮、白眼、抓狂、喝奶、doge、头秃、暗中观察、饥饿、可爱、举牌牌、喝彩、胜利

表情名与对应的 `face_id` 维护在 `status.py` 的 `diy_face_mapping` 中。如需新增/调整可用表情，在该映射表里补全「表情名 → face_id」即可，新增的表情名会自动出现在 `{supported_diy_emojis}` 提示词占位符中。如果模型传入了不支持的表情名，工具会返回失败信息并附带当前可用表情列表。

## 行为说明

插件当前的设计边界如下：

- 头像：可由 LLM 工具根据用户自然语言请求修改
- 昵称：可由 LLM 工具修改
- 个性签名：可由 LLM 工具修改
- 在线状态：可由 LLM 工具修改
- 自定义状态：可由 LLM 工具修改（状态表情 + 自定义文字，仅 NapCat 协议端支持）

也就是说，这个插件整体上是让 LLM 统一接管 QQ 展现层资料修改，但头像仍然要求消息上下文里真实存在图片。

## 注意事项

- 本插件依赖协议端对相关 QQ 资料接口的支持情况
- 不同实现对头像、昵称、签名、状态接口的兼容程度可能不同
- 当前主要面向 `aiocqhttp` 使用
- 若用户要求换头像，但当前消息和引用消息都没有图片，头像工具会提示失败
